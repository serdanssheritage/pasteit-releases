# PasteIT

A clipboard manager for Mac: copy history, workspaces, Private, annotated screenshots and **Save to PasteIT** (right-click an image or video to keep it for later).

## ⬇️ Download

**[Download the latest version (PasteIT.dmg)](https://github.com/serdanssheritage/pasteit-releases/releases/latest)** → under **Assets**, click `PasteIT-<version>.dmg`.

Requires macOS 14 or later.

## Install

1. Open the DMG and drag **PasteIT** into **Applications**.
2. Open PasteIT. macOS says it can't verify the app (it hasn't gone through Apple's paid notarization), so click **Done**.
3. Go to **System Settings → Privacy & Security**, scroll down to PasteIT, click **Open Anyway** and confirm.

   Or run one command in Terminal:

   ```bash
   xattr -dr com.apple.quarantine /Applications/PasteIT.app
   ```

4. Allow **Accessibility** (for direct paste) when PasteIT asks.

Open it with **⌘⇧P**. New versions arrive automatically (Settings → General → Updates).

# PasteIT (Български)

Clipboard manager за Mac: история на копираното, workspaces, Private, скрийншоти с анотации и **Save to PasteIT** (десен клик върху снимка или видео и го пазиш за по-късно).

## ⬇️ Изтегляне

**[Изтегли последната версия (PasteIT.dmg)](https://github.com/serdanssheritage/pasteit-releases/releases/latest)** → в секцията **Assets** натисни `PasteIT-<версия>.dmg`.

Изисква macOS 14 или по-нов.

## Инсталиране

1. Отвори DMG-то и плъзни **PasteIT** в **Applications**.
2. Отвори PasteIT. macOS ще каже, че не може да провери приложението (не е минало през платената проверка на Apple), затова натисни **Done**.
3. Отвори **System Settings → Privacy & Security**, най-долу при PasteIT натисни **Open Anyway** и потвърди.

   Или с една команда в Terminal:

   ```bash
   xattr -dr com.apple.quarantine /Applications/PasteIT.app
   ```

4. Разреши **Accessibility** (за директно поставяне), когато PasteIT поиска.

Отваряне: **⌘⇧P**. Новите версии идват автоматично (Settings → General → Updates).
